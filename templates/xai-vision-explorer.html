This bundled example contains both animals. The overlays are precomputed outputs from a ResNet50 ImageNet example using Grad-CAM; this page does not run the model.

Read the map carefully: warmer areas have stronger Grad-CAM response for the selected class in this model. The map is coarse evidence, not proof of what the model “understood,” and it does not show confidence.

Source, licensing, and what runs here

The input photo and precomputed class overlays come from the pytorch-grad-cam example repository: dog_cat.jfif, resnet50_dog_gradcam_cam.jpg, and resnet50_cat_gradcam_cam.jpg. Its README lists the overlays under ResNet50 examples. This page switches among bundled files; no upload, model inference, or external image request is used.
