See the toy model’s rule

Cat score = 34 + 18×whiskers + 16×pointed ears − 22×long snout + 26×grass. Each cue is between 0 and 1; the label changes at 50. The bars are exact arithmetic for this rule, not an explanation generated for a real neural network.
